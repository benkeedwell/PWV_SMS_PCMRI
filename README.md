Script, functions and data for "Pulse wave velocity measurements in the internal carotid arteries using simultaneous multi-slice phase contrast MRI as an assessment of local arterial stiffness"

By Benjamin Keedwell, Aaron T. Hess, Thomas W. Okell, Iulius Dragonu, Yang Ji, and Peter Jezzard

See LICENSE for conditions of use.

The full reconstruction and analysis can be run from 'Run.m'. However, due to concerns regarding participant anonymity, data is not provided to run the image reconstruction or vessel segmentation. See 'Run.m' for further details.

Data is provided in '20260306_A', '20260317_B' etc., organised by participant. 'age.xlsx' and 'pl.xlsx' provide further age and pathlength data, respectively.

'Functions' includes all functions required to run 'Run.m'. These are organised into the main pipeline functions ('Pipeline'), supporting functions ('Supporting'), and functions developed by non-authors ('Other').

When using this work, please cite the paper.
